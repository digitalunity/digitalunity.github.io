Hexjack Lens · How it works

One controlled research layer across the information estate.

Lens gives authorised AI clients a stable way to discover and research configured organisational sources without exposing every provider API, credential or execution environment directly.

Configured sources

Documentation, issue and service systems, repositories and other approved sources are represented through explicit identities and capabilities.

Bounded operations

Sources advertise only the operations they support: typically search and retrieve, with investigation available only where explicitly configured.

Common evidence

Results retain provenance and common semantics instead of leaking each provider's internal API model into every AI client.

Retrieve

Find what the organisation already knows.

Retrieval searches and reads existing information from authorised sources. It is intentionally bounded: the caller selects configured contexts and sources rather than arbitrary hosts, filesystems or network destinations.

Provider-specific details stay behind Lens while source identity, freshness and provenance remain visible where useful.

Investigate

Establish new findings when retrieval is not enough.

Some questions require more than search: following code paths, testing hypotheses or examining an authorised development environment. Lens can delegate such a question through a provider-neutral Analysis Engine Contract.

The analysis environment remains a separate trust boundary. Lens passes a bounded question and authorised context rather than exposing generic shell, database or execution access to the AI client.

Provider neutral

Same Lens. Different estates. Different analysis environments.

The product architecture separates the information-estate interface from provider implementations. Organisations can choose the systems and analysis environments appropriate to their own estate without changing the fundamental Lens contract.

Evidence survives the journey.

Retrieval and investigation both feed a common model that keeps source evidence, observations and inference distinct.
